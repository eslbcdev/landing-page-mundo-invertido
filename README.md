Uma jornada para quem não tem medo do desconhecido. O caminho para o Mundo Invertido é incerto, repleto de obstáculos e perigos. Porém, a recompensa é grande: salvar Hawkings e o mundo todo das garras de Vecna. Você está preparado(a)? 

Este projeto foi desenvolvido durante o evento Semana Front-end, com o objetivo de criar uma landing page imersiva com a temática da série Stranger Things, aplicando conceitos de HTML, CSS e JavaScript com integração a um banco de dados (Firebase).

## ✨ Sobre o Projeto
A aplicação é uma landing page que convida o usuário a "entrar no Mundo Invertido". O projeto foi construído ao vivo em duas lives, explorando desde a estruturação semântica do HTML até a manipulação de dados em tempo real com Firebase, passando por estilizações avançadas e animações com CSS.

## 💻 Tecnologias e Conceitos Abordados
O foco do projeto foi aplicar de forma prática os seguintes pilares do desenvolvimento front-end:

* **HTML:**
  * Estruturação da Página: Criação do layout principal do site.

  * Semântica e Acessibilidade: Uso correto das tags para garantir um site mais acessível e otimizado.

  * SEO: Boas práticas para melhorar o ranqueamento em motores de busca.

  * Web Scraping: Conceitos introdutórios sobre extração de dados da web.

* **CSS:**
  * Posicionamentos: Uso de relative, absolute, fixed para controlar os elementos.

  * Pseudo-elementos e Pseudo-classes: Para estilizações detalhadas e efeitos interativos.

  * Flexbox: Para criação de layouts flexíveis e responsivos.

  * Animações: Uso de @keyframes, transform e transition para dar vida à página.

* **JavaScript:**
  * Introdução e Manipulação do DOM: Para criar interatividade e alterar elementos da página dinamicamente.

  * Integração com Firebase:

  * Introdução ao Firebase (Backend as a Service).

  * Gravação de dados de usuários (inscritos na "jornada") no banco de dados Firestore.

## 📚 Objetivos de Aprendizagem
Construir uma página web temática e interativa do zero.

Aplicar conceitos de HTML semântico, acessibilidade e SEO.

Criar layouts complexos e animações com CSS moderno.

Desenvolver a interatividade da página com JavaScript e manipulação do DOM.

Realizar a integração de um projeto front-end com um serviço de backend (Firebase) para persistência de dados.

## ✨ About the Project
The application is a landing page that invites the user to "enter the Upside Down." The project was built live over two sessions, exploring everything from semantic HTML structure to real-time data handling with Firebase, including advanced styling and animations with CSS.

## 💻 Technologies and Concepts Covered
The project's focus was to practically apply the following pillars of front-end development:

* **HTML:**
  * Page Structuring: Creating the main layout of the website.

  * Semantics and Accessibility: Correct use of tags to ensure a more accessible and optimized site.

  * SEO: Best practices to improve search engine rankings.

  * Web Scraping: Introductory concepts on web data extraction.

* **CSS:**
  * Positioning: Using relative, absolute, and fixed to control elements.

  * Pseudo-elements and Pseudo-classes: For detailed styling and interactive effects.

  * Flexbox: For creating flexible and responsive layouts.

  * Animations: Using @keyframes, transform, and transition to bring the page to life.

* **JavaScript:**
  * Introduction and DOM Manipulation: To create interactivity and dynamically change page elements.

  * Firebase Integration:

  * Introduction to Firebase (Backend as a Service).

  * Saving user data (subscribers to the "journey") to the Firestore database.

## 📚 Learning Objectives
To build a thematic and interactive web page from scratch.

To apply concepts of semantic HTML, accessibility, and SEO.

To create complex layouts and animations with modern CSS.

To develop page interactivity using JavaScript and DOM manipulation.

To integrate a front-end project with a backend service (Firebase) for data persistence.
